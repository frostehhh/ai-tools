# AI Tools

A repository for common configuration for agentic AI tools like Claude Code and OpenSpec.

## Directory Structure

### `.agents/`
Generic AI config directory created with Vercel Skills `npx skills *`

### `.claude/`
Configuration directory for Claude Code

### `openspec/` - OpenSpec
A spec-driven development framework for generating structured planning artifacts. This directory contains custom workflows defined under the `schemas` directory.

Working with OpenSpec:
- Install or update the OpenSpec CLI via `npm install -g @fission-ai/openspec@latest`
- Run `openspec init` in the project you need to work in
- Run `openspec update` in the project if you need to update the generated files

See the [OpenSpec repository](https://github.com/Fission-AI/OpenSpec) for more information
