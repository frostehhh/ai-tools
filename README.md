# AI Tools

A repository for common configuration for agentic AI tools like Claude Code, opencode and OpenSpec.

The shareable config lives under `src/`. The `.agents/skills/` at the repo root holds helper skills for working in this repo itself.

## Directory structure

```
ai-tools/
├── .agents/skills/        # repo-root helper skills: link-skills, sync-links, show-me, write-a-skill
├── src/                   # shareable AI configuration
│   ├── .agents/skills/    # SOURCE OF TRUTH for all skills (real folders; pointer files for external skills)
│   ├── .claude/           # Claude Code config; skills/ are pointer files into .agents/skills
│   ├── .opencode/         # opencode config: opencode.jsonc + agents/
│   ├── openspec/          # OpenSpec workspace (config.yaml, schemas/)
│   ├── skills/<category>/ # GENERATED by-category junctions (gitignored): general/, frontend/
│   ├── skills-lock.json   # Vercel Skills lock file
│   └── AGENTS.md          # shared conventions
├── tools/
│   ├── linkSkills/        # sync.ps1 + categories.json: .agents/skills → generated skill junctions
│   ├── syncLinks/         # sync.ps1 + links.json consumer: create / repair / audit links
│   └── herdr-plugins/     # local Herdr plugins (machine-specific)
├── links.json             # map of every link from this repo to its consumers
└── AGENTS.md              # repo-specific instructions
```

## Skills

- Edit skills only in `src/.agents/skills/<name>`. Skills are created with Vercel Skills (`npx skills *`); the lock file is `src/skills-lock.json`.
- `src/skills/<category>/` is a generated by-category view (directory junctions, gitignored). `src/.claude/skills/<name>` are git pointer files into `src/.agents/skills`.
- After adding, removing or renaming a skill, or after a fresh clone, run `pwsh tools/linkSkills/sync.ps1`. Category comes from `tools/linkSkills/categories.json`.

## OpenSpec

A spec-driven development framework for generating structured planning artifacts. Custom workflows live under `src/openspec/schemas`.

Working with OpenSpec:
- Install or update the OpenSpec CLI via `npm install -g @fission-ai/openspec@latest`
- Run `openspec init` in the project you need to work in
- Run `openspec update` in the project if you need to update the generated files

See the [OpenSpec repository](https://github.com/Fission-AI/OpenSpec) for more information.

## Tools

Each tool has its own README.

- `tools/linkSkills/` — builds the generated skill junctions from `src/.agents/skills` and `categories.json`.
- `tools/syncLinks/` — creates, repairs and audits every link in `links.json`.
- `tools/herdr-plugins/` — local Herdr plugins (machine-specific).
