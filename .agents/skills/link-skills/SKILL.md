# link-skills

`src/.agents/skills/<name>` is the only place skills are edited. The by-category view is generated junctions (gitignored). Full details: `tools/linkSkills/README.md`.

## Run

From the repo root:

```
pwsh tools/linkSkills/sync.ps1
```

Restart opencode afterwards.

## What it does

- Reads every entry in `src/.agents/skills`. A plain file is a pointer (git symlink checked out with `core.symlinks=false`); its content is the target directory.
- Deletes and recreates one junction per skill in `src/skills/<category>/`.

## Categories

`tools/linkSkills/categories.json`: first match of explicit name in `categories`, then longest prefix in `prefixes`, then `default` (`general`). Categories only change the folder under `src/skills/`, never the skill name.

## Rules

- Never put real content in `src/skills/*`.
- Real files and folders in the generated dirs are reported, never deleted.
- Never `-Recurse` delete a junction; use `cmd /c rmdir <link>`.
- Windows only, needs `pwsh`. Junctions need no admin rights.
