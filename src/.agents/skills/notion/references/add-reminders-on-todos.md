# Add reminders on to-dos

To-dos Today ongoing due view
https://app.notion.com/p/2bd50704f72a805e9d04d6579525537f?v=2c050704f72a801bb0d3000cde4bb585&source=copy_link

See the records in the linked view above. Get and list the entries that have `Due` date values. List them in a markdown table with the following columns:
- Note name
- Due

Ask the user if they want to proceed with setting the reminder to at the time of the start due date.
