# Task Management

Only for questions or changes about the user's task management system: the Notion To-dos pages, planning, views, Foundation Tasks, and the Plan Today / Today / Weekly Review pages.

## Source of truth: Obsidian Odyssey vault
`Personal Odyssey/Guidelines and To-dos/Self-management/Task Management/`
- `Task Management Guidelines Overview.md`: objectives, current Notion design (nav layout, `Task Type` and helper formulas, views by page), change log, cleanup checklist, time budgets and decision models. Read first.
- `Notes/Plan Today.md`, `Notes/Today.md`, `Notes/Weekly Review.md`: purpose, checklist and view definitions for each entry page. Read the one that matches the request.

Use the vault for guidelines and design intent. Use Notion for live data (tasks, current views).
